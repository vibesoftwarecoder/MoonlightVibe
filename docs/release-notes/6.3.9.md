**This release catches up with nine commits from upstream moonlight-qt, including a change to the default streaming resolution.**

## What changes

- **The default streaming resolution is now 1080p**, matching upstream's new default.
- Three MSI-signing fixes from upstream (don't require `SIGNTOOL_PARAMS` to contain the `sign` command; require it to be set externally). No effect today — we don't currently sign the Windows installer with a real certificate — but keeps us in step with upstream's signing path for if that changes.
- `libplacebo`, `sdl2-compat`, and `SDL3` dependency updates.
- Windows CI updated to Qt 6.12.
- Two Linux-only fixes: matching colon-separated `XDG_CURRENT_DESKTOP` values, and checking `elf_aux_info()`'s return value in `hasFastAes()`.

None of this touches MoonlightVibe's own 47-file delta from upstream — our microphone capture, computer-model extensions, stream-settings additions, and gamepad quit combo are all unchanged.

## Who this affects

Anyone who relied on the previous default resolution without setting one explicitly will see 1080p now instead of whatever the old default was. Everyone else is unaffected.

## How this was checked

Both the Windows and macOS builds were verified with a real manual dispatch against the merge branch before it ever touched `master` — both completed successfully.

**macOS specifically re-verified against the recent #13 regression risk**, since that fix has already been through two rounds of a green build not meaning what it looked like it meant: confirmed directly in the build log that the `macdeployqt` bundle-binary/rpath errors are still absent, the linker and codesign both correctly reference `Contents/MacOS/MoonlightVibe`, and the resulting artifact is 78.7MB — matching the known-good fixed build, not a silently incomplete one.

Not runtime-tested on a real client — this host is headless Windows; this is a Qt desktop client.

## Install

Download the asset for your platform from the release. Windows: unzip and run. macOS: open the DMG, drag to Applications — you'll likely see an "unidentified developer" prompt on first launch, which is expected; use right-click → Open, or System Settings → Privacy & Security → Open Anyway.
