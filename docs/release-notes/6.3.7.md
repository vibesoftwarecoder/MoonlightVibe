**This release fixes macOS installs that showed "MoonlightVibe can't be opened because it is damaged or incomplete" on first launch.**

## What was happening

Issue #13: on Apple Silicon Macs, MoonlightVibe failed to open after installing from the DMG, across multiple versions, while stock upstream Moonlight worked fine. The cause: our macOS build pipeline has never had a real signing identity or notarization configured, so every macOS release shipped as a completely unsigned app bundle — not even ad-hoc signed. macOS Gatekeeper refuses to launch a fully unsigned arm64 app after download and reports it as "damaged," rather than the more familiar, user-bypassable "unidentified developer" warning (that prompt only appears for an app signed at least ad-hoc).

## What changes

The build now ad-hoc signs the app bundle when no real Developer ID is configured (which is every build today), instead of skipping signing entirely.

## Who this affects

Anyone installing MoonlightVibe on an Apple Silicon Mac. Intel Macs were likely less strict about this, so the symptom may have been Apple-Silicon-specific.

## How this was checked

This host can't run `codesign`/`create-dmg`/build a macOS app at all, so the actual build+sign was verified for real on GitHub's macOS runner, both as part of this fix's own PR and as a manual dispatch against the branch before merging. The job completed successfully and the new ad-hoc `codesign` step ran without error.

**What this doesn't confirm:** whether the resulting signature actually satisfies Gatekeeper in practice. This needs a real Apple Silicon Mac to test — which is exactly why we're asking for your help confirming it (see #13).

**This doesn't eliminate every Gatekeeper prompt.** You'll likely still see "unidentified developer" on first launch — that's expected and normal, and bypassable via right-click → Open, or System Settings → Privacy & Security. Eliminating that too would need real notarization, which needs a paid Apple Developer account — a separate decision.

## Install

Download `MoonlightVibe-mac-6.3.7.dmg` from the release, drag to Applications, right-click → Open on first launch if macOS warns about the developer.
