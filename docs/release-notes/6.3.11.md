**This release adds USB forwarding to the Windows client, as an experimental feature that is off by default, and catches up with 28 commits from upstream moonlight-qt.**

## What changes

- **USB forwarding (Windows only, off by default).** A new "USB forwarding" section in Settings lets you share a USB device from your PC and have it appear on the host you are streaming to. Share and Stop sharing buttons, a "Forward automatically when streaming" option for each device, and Ctrl+Alt+Shift+U to pause or resume. With the setting off, nothing is created and a stream behaves exactly as before.
- Upstream moonlight-qt fixes, mostly error handling: the libplacebo, EGL, VAAPI and VDPAU renderers, a failed H.264 SPS read, the adaptive-trigger controller check, and a TCP/TLS HTTP timeout on Qt 6.3 and newer. One of them makes the client refuse to open a log file that already exists.
- A macOS fix for a reduced mouse polling rate.

## What USB forwarding needs

- **On the PC you stream from:** Windows, with `usbipd-win` installed. Sharing a device asks for administrator approval.
- **On the host:** an ApolloVibe build with USB forwarding turned on in its settings, the `usbip-win2` driver, and the USB permission granted to your client in Apollo's client list. Stock Apollo and Sunshine do not support it.
- Plug in a USB stick or a spare gamepad to try it. A keyboard or mouse is not a good first device.

## Who this affects

Nobody who leaves the USB setting off. Everyone gets the upstream fixes.

## How this was checked

- The USB client code has 323 automated tests passing across 11 projects. They run on the loopback interface with fake servers, and each security check was broken on purpose to confirm a test fails.
- Both the Windows and macOS builds passed against the latest upstream merge branch before it reached `master`.

**Not yet proven end to end.** The host side was set up on 2026-10-28 and a client reached it and asked to attach a device, but the device did not appear on the host in that first attempt. We have not yet found out why. Treat USB forwarding as experimental until a device has been confirmed working.

Not runtime-tested on a real client beyond that attempt. This is a Qt desktop client.

## Install

Download the asset for your platform from the release. Windows: unzip and run. macOS: open the DMG, drag to Applications — you'll likely see an "unidentified developer" prompt on first launch, which is expected.
