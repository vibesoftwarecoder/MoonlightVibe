**Upstream frame-loss fixes.** This release exists to pick up
[`moonlight-common-c` frame loss fixes](https://github.com/moonlight-stream/moonlight-qt) from
upstream `moonlight-stream/moonlight-qt`, merged into MoonlightVibe on 2026-09-09.

MoonlightVibe is now level with upstream — **0 commits behind**.

## What changed

The only shipping change is the `moonlight-common-c` submodule pin, moved to pick up the frame-loss
work. Everything else in this release is identical to 6.3.2.

⚠️ **The fixes are in the streaming path**, so if you were seeing dropped or corrupted frames, this
is the release to try. If your stream was already clean, you are unlikely to notice a difference.

## The microphone fork is preserved

MoonlightVibe pins `moonlight-common-c` to **our own fork**, which carries microphone passthrough.
Upstream's fixes were merged **into** that fork rather than replacing it, so mic support is intact —
this is not a switch back to stock `moonlight-common-c`.

## Still included

All MoonlightVibe patches: mic passthrough, per-seat stream settings, latency tuning, and the
configurable gamepad quit combo.

Windows and macOS assets are attached to this same release.

## Note on versioning

The version comes from `app/version.txt`, and a `v*` tag that disagrees with it fails the release
rather than shipping a binary that claims a version no release has.
